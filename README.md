# Watoskop – projekt „Energia pod kontrolą”

Pliki:
- `Watoskop_prezentacja.pptx` – 18 slajdów (etapy 1–9)
- `Watoskop_biznesplan.xlsx` – biznesplan 12 mies. (+ rozszerzenie do M24), 3 scenariusze, formuły; źródło liczb: arkusz „Założenia” (żółte pola)
- `Watoskop_reklama.mp4` – 16-sekundowy spot; `build/` – skrypty i grafiki

Model danych: falowników nie kupujemy – integracja z API chmur producentów (Huawei, Growatt…) + import CSV; dla firm bez PV bramka pomiarowa kupowana od dystrybutora.

Do samodzielnej weryfikacji (wymóg projektu): dostępność nazwy/domeny/znaku (UPRP, EUIPO), kody PKD 2025, opłaty rejestracyjne, ceny bramek, dostępność API producentów, ceny i oferty konkurentów, udział 20%/15%/2% w rynku (założenia własne), wyniki ankiety (nie zostały zebrane – slajd 8 opisuje plan badania).
Dane o liczbie firm: Raport PARP o stanie MŚP 2026.
